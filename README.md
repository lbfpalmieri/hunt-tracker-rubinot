# RubinOT Hunt Tracker

Queria algo para monitorar meu desenvolvimento nas hunts do tibia, algo que eu conseguisse importar os dados fornecidos dentro do Tibia (no caso é um servidor alternativo chamado RubinOT), a ideia seria ter um acompanhamento de lucro, xp, monstros por hora, monstros totais, nome da hunt, vincular o personagem ao sistema de alguma forma... entre outras coisas, vou anexar em doc simples o formato do hunting analyser, do miscellaneous e do input analyser. A interface precisa ser bem dinamica, minimalista porem moderna, com um tema mais dark no fundo mas o resto com cores fortes. Precisa ser bem focado no Rubinot, vou passar o logo para vc incluir na interface, e coloca que foi desenvolvido pelo canal @Ésobrerubinot (É sobre RubinOT.)
